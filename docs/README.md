## Recommended Reading Order

1. Start with `README.md` in the repository root.
2. Read `docs/USER_GUIDE.md` for application behavior and user flows.
3. Read `docs/API_DOCUMENTATION.md` for endpoint-level integration details.
4. Read `docs/DEVELOPER_GUIDE.md` for architecture, local development, and testing.
5. Read `docs/DEPLOYMENT_GUIDE.md` for production setup and operations.
6. Read `docs/ADMIN_GUIDE.md` if you operate or support customer subscriptions.
